CAMPUS HEAD BALL — MOBİL GÜNCELLEME

1) Bu klasörün İÇİNDEKİ her şeyi GitHub Desktop'taki campus-head-ball depo klasörünün köküne kopyala.
2) MOBIL_GUNCELLE.command dosyasına çift tıkla.
3) macOS ilk açılışta izin vermezse: sağ tık > Aç > Aç.
4) "TAMAMLANDI" mesajını gördüğünde GitHub Desktop'a dön.
5) Commit mesajı: 5.8.0 iPhone joystick ve PWA
6) Commit to main > Push origin.
7) Render deploy bitince iPhone Safari'de https://kafatopu.onrender.com aç.

KONTROLLER
- Sol joystick sağ/sol: hareket
- Joystick yukarı: zıplama
- Joystick aşağı: eğil / hızlı in
- J: kafa vuruşu
- K: özel güç
- Oyun ekranı portredeyse yataya çevirme uyarısı çıkar.
